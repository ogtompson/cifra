# Cifra — frontend

Interface web do Cifra, construída com Next.js, React, JavaScript e Tailwind CSS.

## Ambiente local

1. Copie `.env.example` para `.env.local`.
2. Mantenha o backend disponível em `http://localhost:8080`.
3. Instale as dependências e inicie o frontend:

```bash
npm install
npm run dev
```

A aplicação ficará disponível em `http://localhost:3000`.

## Comandos

```bash
npm run dev
npm run lint
npm run build
npm start
```

`NEXT_PUBLIC_API_URL` define o endereço-base da API usado pelo navegador.
